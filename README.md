# hudson-bay-lowlands-climate-indicators-2023

Code and data to replicate the results of the 2023 publication in FACETS "Snow, ponds, trees, and frogs: how environmental processes mediate climate change impacts on four subarctic terrestrial and freshwater ecosystems"; dx.doi.org/10.1139/facets-2022-0163

Data, figures, and .R scripts used to produce the figures and analyses presented in the paper and provided here. 

Package prerequistes are detailed in the .R scripts.

Further details on the aquistion of Coupled Model Intercomparison Project Phase 5 data is avliable in the open-access publication: https://www.facetsjournal.com/doi/10.1139/facets-2022-0163
